# Data License and Provenance

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](LICENSE-DATA.vi.md)

The canonical demo dataset contains structured facts derived from **Wikidata**.

Wikidata structured data is published under the **Creative Commons CC0 1.0 Universal** dedication.

- Source: Wikidata
- Source license: CC0 1.0
- Derived canonical dataset license: CC0 1.0
- Included: labels, descriptions, aliases, QIDs and structured identifiers
- Excluded: Wikipedia article bodies, news text, Common Crawl and arbitrary copyrighted website prose

Attribution is not required by CC0, but the project retains source QIDs and provenance so users can inspect where structured facts originated.

The repository software itself is licensed separately under MIT.
